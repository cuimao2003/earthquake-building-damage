# 跨震区混合训练记录（2026-11-27 第二轮）

## 数据

- 新增 **xBD 帕卢 2018 地震 + 海啸** 数据（本地 xBD 原始数据中此前未使用）：
  - 训练：113 对影像，标注 25,455 栋未受损、571 栋重损、4,966 栋毁坏、1 栋轻损、401 栋未分级；
  - 官方测试：42 对影像，标注 10,927 栋未受损、250 栋重损、1,237 栋毁坏（无轻损），作为**跨地震独立测试集**（按官方 xBD train/test 划分，未参与训练）。
- 混合清单 `data/manifest_plus_palu.json`：train = 墨西哥 130 + 帕卢 113 = **243 对**；val = 墨西哥 27 对；test = 墨西哥 34 对。
- 新特征缓存 `data/proposal_palu_mix`（5.3 GB，243 + 27 场景，ViT-B/14 168px）。

## 结果（同一验证/测试口径）

| 模型 | 墨西哥验证 27 对（宏 F1 / 损伤档 F1） | 墨西哥 34 对留出（宏 F1 / 框 F1） | 帕卢 42 对端到端（宏 F1 / 损伤档 F1 / 重损 F1） | 帕卢给人工框（准确率 / 重损 F1） |
|---|---:|---:|---:|---:|
| 旧模型（ViT-L+ViT-B 分级器） | 0.2296 / 0.0708 | 0.1557 / 0.4731 | 0.1713 / 0.0020 / — | 0.880 / 0.009 |
| 墨西哥单区 pooled 头（此前） | 0.2013 / 0.0333 | — | — | — |
| **混合 pooled（基础损失）** | 0.2137 / 0.0471 | **0.1561 / 0.4732** | **0.3283 / 0.2322 / 0.4643** | **0.907 / 0.683** |
| 混合 attention | **0.2193 / 0.0640** | — | 0.2890 / 0.1904 / 0.3808 | 0.805 / 0.526 |
| 混合 pooled + ranking/focal + 重损采样 40 | 0.2081 / 0.0387 | — | 0.2949 / 0.1976 / 0.3952 | 0.816 / 0.545 |

## 结论

- 加入帕卢训练后，**跨地震损伤识别大幅提升**：端到端三档宏 F1 0.1713 → 0.3283，重损 F1 0 → 0.4643（TP 625），给人工框时重损 F1 0.009 → 0.683（召回 83%、精确率 58%）。
- **没有牺牲墨西哥表现**：34 对历史留出 0.1561（旧模型 0.1557，基本持平）；墨西哥验证从 0.201~0.207 升到 0.214~0.219。
- 评审建议的 ranking/focal 损失 + 重损采样 10→40 没有超过基础混合模型；最优检查点仍在第 4 轮附近，说明小数据下仍是 early-stop 主导。
- attention 版墨西哥验证最高（0.2193），但帕卢端到端低于 pooled（0.2890 vs 0.3283），按用途取舍。
- 局限：帕卢训练/测试同属一场地震（官方 split 的不同切片），不是完全独立的跨事件证据；下一步用土耳其 2023（KATE-CD/Maxar+EMS）补真正跨事件验证。

## 追加：KATE-CD 独立验证、融合与 bootstrap（2026-11-27 晚）

### KATE-CD（土耳其 2023）独立像素级损伤验证

把模型预测的受损建筑框栅格化，与数据集二值损伤掩膜比较（44 张验证切片）：

| 模型 | 像素损伤精确率 | 召回率 | F1 | IoU |
|---|---:|---:|---:|---:|
| 旧模型 | 0.103 | 0.191 | 0.134 | 0.072 |
| 混合 pooled | 0.148 | 0.423 | **0.220** | 0.123 |
| 混合 + KATE 辅助 | 0.085 | **0.612** | 0.150 | 0.081 |

混合训练在未参与训练的土耳其 2023 数据上同样提升（F1 0.134 → 0.220）；KATE 辅助训练把召回推高到 0.61 但精确率骤降，说明只加二值辅助损失会造成过报，不采用。

### 融合（墨西哥口径）

| 配置 | 融合权重（轻损/重损） | 墨西哥验证宏 F1 | 损伤档 F1 | 34 对留出宏 F1 | 帕卢端到端宏 F1 |
|---|---|---:|---:|---:|---:|
| 混合 pooled | — | 0.2137 | 0.0471 | 0.1561 | **0.3283** |
| 混合 pooled + 旧模型 | 0.8 / 0.0 | **0.2388** | 0.0835 | **0.1566** | 0.1712 |
| 0.24 缓存注意力头 + 旧模型 | 1.0 / 0.2 | 0.2359 | **0.0909** | 0.1535 | 0.1799 |

融合能把墨西哥验证推到 0.2388，但它把旧模型的“不识别跨震区损伤”带回，帕卢退化；因此最终提供两个口径：**墨西哥优先用融合配置，跨震区/未知震区用混合模型本体**。

### bootstrap 置信区间（27 场景重采样 1000 次）

| 模型 | 宏 F1 点估计 | 95% CI | 损伤档 F1 95% CI |
|---|---:|---|---|
| 混合 pooled | 0.2136 | [0.1755, 0.2463] | [0, 0.1015] |
| 混合 + KATE 辅助 | 0.2124 | [0.1818, 0.2489] | [0.0062, 0.0984] |

墨西哥验证集只有 37 栋轻损、10 栋重损，任何 <0.02 的差异都落在重采样区间内；跨事件 0.17→0.33 的提升不受此影响。


### 附加实验：复用旧流水线微调过的 DINOv2 编码器（评审建议 E2）

从旧模型 `run/mexico_vitb168/mexico_vit.pt` 中取出微调后的 ViT-B/168 编码器，用同一候选框流程重建缓存 `data/proposal_vitb168_ft`（墨西哥 130 + 27 场景），训练 pooled / attention 分级头：

| 配置 | 墨西哥验证宏 F1 / 损伤档 F1 | 融合（权重） | 帕卢端到端宏 F1 / 损伤档 | KATE-CD 像素损伤 F1 |
|---|---:|---|---:|---:|
| 微调编码器 pooled | **0.2211** / 0.0571 | 0.2359（[0.0, 1.0]） | 0.1704 / 0.0013 | 0.024 |
| 微调编码器 attention | 0.2126 / 0.0455 | — | — | — |
| 对照：混合 pooled（raw 编码器） | 0.2137 / 0.0471 | 0.2388（[0.8, 0.0]） | **0.3283 / 0.2322** | **0.220** |

- 微调编码器把墨西哥验证单头推到 0.2211（单头最高），但轻损预测数被 validity 阈值压到 0、重损 F1 仅 0.1143，且融合后 0.2359 仍低于混合融合的 0.2388。
- 跨震区严重退化（帕卢 0.1704、KATE 0.024）：旧编码器是在墨西哥旧任务上微调的，领域偏移被放大。
- 结论：不采用。最终推荐仍是「墨西哥口径用 mix_fusion（0.2388 / 留出 0.1566），未知震区用 mix_palu_pooled（帕卢 0.3283 / KATE 0.220）」。
