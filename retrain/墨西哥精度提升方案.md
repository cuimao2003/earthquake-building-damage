# 提升墨西哥精度：文献调研 + 本项目误差预算 + 实验路线（2026-11-27）

## 1. 先校准指标口径（最重要）

- 文献在 xBD/xView2 上报的 0.8 左右，基本是**像素级 xView2 综合分**（=0.3×定位 F1 + 0.7 损伤 F1，且只在 GT 建筑区域内计分），不是建筑级三档宏 F1。xBD 官方基线定位 F1 约 **0.80**，但损伤 F1 只有 **0.03**；按建筑实例（给定多边形）的各类 F1 为无损伤 0.66 / 轻损 0.14 / 重损 0.01 / 毁坏 0.47，宏 F1 ≈ **0.32**。BDANet 0.806、DAHiTrA 0.819 仍是像素口径；即便给定真值框，实例级图块分类的加权 F1 也只有 0.53–0.60，轻损 F1 约 0.14。
- 因此：**在本项目“建筑级三档宏 F1、自动定位”的口径下，0.8 与文献数字不可直接比较，也缺乏可复现的公开先例。** 合理目标应是：
  - 定位 F1（IoU 0.5）向 0.75–0.85 靠拢；
  - 给定人工框的分级宏 F1 从 0.31–0.45 提到 0.50–0.60；
  - 端到端宏 F1 从 0.156 提到 0.30–0.45；
  - 同时报告 xView2 像素综合分，便于与论文对比。

## 2. 本项目误差预算（2026-11-27 实测）

- 定位上限：Swin 检测器默认阈值 0.36 时，即使分级全对，验证集建筑级宏 F1 上限也只有 **0.748**；降到 0.24 为 **0.822**、0.12 为 **0.860**（`run/proposal_location_audit/location_audit.json`）。→ 想上 0.8，必须用更低候选阈值 + 强误报过滤。
- 分级上限：给定人工框、阈值按 LOSO 校准后，新分级头宏 F1 只有 **0.34（pooled）/0.33（attention）**，旧模型约 **0.45**；轻损/重损 F1 接近 0。→ 分级本身是比定位更大的瓶颈。
- 误差构成：旧模型验证集 37 栋轻损只判对 4 栋、10 栋重损判对 1 栋；未受损假阳性约 2,900 个（48% 候选框未匹配）。定位召回不足（27/37、5/10）与误报同时存在。
- 验证集损伤样本只集中在 8 个场景（其中 2 个场景占 25/47 栋），单栋变化就能让宏 F1 波动约 0.01–0.02，小样本下任何微调都不显著（bootstrap 95% CI [0.18, 0.25]）。

## 3. 论文/竞赛可借鉴的方法（按可行性排序）

### A. 直接可实施

1. **复刻 xView2 冠军方案**（Durnov, 2020，[代码](https://github.com/DIUx-xView/xView2_first_place)）：先用震前影像训练 UNet 做定位，再用 Siamese 分级；对损伤类过采样 2×、Focal+Dice+CE、损伤 mask 5×5 膨胀、轻损重叠优先、受损类定位阈值降低、4×TTA。竞赛综合分约 0.75（简化版 0.73）。→ 可把定位从检测框升级为分割实例，定位 F1 有望 0.55→0.75+；但 8GB 单卡每轮 0.5–1 小时。
2. **定位/分级解耦诊断 + 按类阈值校准**：给定 GT 框测分级上界，再按类网格选阈值（我们已实现 `given_box_diagnostic.py`，可继续做 LOSO 阈值表）。→ 只改评估，成本低。
3. **检测器双时相融合 + 震后随机平移增广**（CVPRW26 论文）：YOLOX-S 在 xBD 上单时相 F1 0.574→Siamese 0.591→加 0–150px 随机平移 0.612。→ 我们的 Swin FPN 可加 `[pre, post, |diff|]` 三路输入 + post 平移增广 + WBF/TTA；推测定位 F1 +0.03–0.05，1–2 小时/轮。
4. **SWA + 单域 batch + 事件级留出**（Benson 2020）：xBD IID 0.74、OOD 0.44；AdaBN+SWA 把 OOD 提到 0.59、gap 从 0.30 降到 0.15。→ 末 10 轮权重平均、每个 batch 只放一个事件、验收改 leave-one-event-out，可让历史留出更稳定；0.3 小时。

### B. 中等改造

5. **提高 token 分辨率**：当前 168px/6×6 池化 ≈28px/token（≈8.4 m），对小区屋顶变化太粗。改 336px 或 12×12 池化/token，预期宏 F1 +0.03–0.06（推测）；8GB 需梯度累积。
6. **LoRA 解冻 DINOv2**（xBD 图块级 0.526→0.565）：最后 6 个 block 加 LoRA + 224 crop + 强光度增广；预期 +0.02–0.05（推测），1–2 小时。
7. **多边形辅助分割**（BDANet / DAHiTrA）：用 xBD 多边形生成建筑 mask + 损伤 mask 辅助头，mask 概率池化进 RoI 分级；像素口径 F1 0.806/0.819、轻损 0.616/0.711。→ 2–4 天，收益最确定但工程量大。
8. **跨事件预训练 + 少样本微调**（GeoBias 2026 等）：全 xBD/帕卢/土耳其预训练，再用少样本微调墨西哥；风险负迁移。

### C. 不建议

- 用 SAM 伪标注轮廓（xBD 上轻量 UNet/SegFormer 已 IoU 0.54–0.60，SAM 无优势）；
- 全量像素级 Transformer 重训（8GB/时间不允许，指标口径也不同）；
- **指望外部墨西哥数据补轻损训练**：EMSR244 只有 3 个 AOI 分级矢量（Atlixco/Tlancualpican/Huehuetlan），UNOSAT 墨西哥城仅 201 栋“潜在受损”（偏重损），CDMX 普查是地址级表格——只能做独立核验，不能补轻损样本。

## 4. 建议的实验路线（单卡 8GB，按优先级）

**第 1 阶段（1–2 天，风险低）**
1. 完成 oracle 诊断与按类阈值表（已起步：`given_box_diagnostic.py` → 自动化 LOSO 阈值表）。
2. 分级增强：损伤类过采样 2×、Focal + 序数损失、mask 膨胀特征、CutMix、类权重；用 3 seed×5 折切片 CV 报告均值±std；验收给定框宏 F1、轻/重损 F1。
3. 检测增强：Swin FPN 加 post 平移增广 + 4×TTA + WBF；验收定位 F1@0.5 与召回。
4. SWA + 单域 batch；验收 34 对留出（只测一次）与帕卢/土耳其跨域 Δ。

**第 2 阶段（2–4 天）**
5. 复刻 xView2 冠军：UNet 定位 + Siamese 分级 + 4×TTA（若定位提升明显，再替换现有 Swin 检测器）。
6. token 升级到 336px/12×12，或 LoRA 解冻后 6 个 block；只改一个变量。

**第 3 阶段（可选）**
7. 多边形辅助分割头 + 两阶段；再考虑融合与最终校准。

**验收口径固定**：验证集用 5 折 LOSO 或 bootstrap 均值±95% CI；34 对历史留出只测一次；帕卢 42 对 + KATE-CD 44 切片做跨域护栏（提升墨西哥时跨域 Δ 不超过 0.02–0.03）。

## 6. 第 1 阶段实测结果（2026-11-27，墨西哥 27 对验证 / 34 对留出）

### 6.1 检测器翻折 TTA + WBF（无需重训）

| 候选设置 | 召回 | 匹配数 | 轻损/重损匹配 | 完美分级宏 F1 上限 |
|---|---:|---:|---:|---:|
| 默认单时相 @0.36 | 0.580 | 3,218 | 27/37、5/10 | 0.748 |
| TTA @0.36 | 0.637 | 3,533 | 29/37、7/10 | **0.827** |
| 默认单时相 @0.24 | 0.674 | 3,740 | 31/37、6/10 | 0.822 |
| TTA @0.24 | 0.730 | 4,050 | 34/37、7/10 | **0.875** |
| TTA @0.12 | 0.826 | 4,583 | 35/37、7/10 | **0.900** |

结论：TTA 把定位上限从 0.748 提到 0.827（0.24 下 0.875），但候选误报同步增加，需要更强的 validity/分级才能变现。

### 6.2 分级增强（同一墨西哥缓存，27 对验证）

| 配置 | 验证宏 F1 | 损伤档 F1 | 34 对留出宏 F1 | 备注 |
|---|---:|---:|---:|---|
| 基线 pooled | 0.2013 | 0.0333 | — | 旧 pooled 头复现 |
| 过采样+重损权重+SWA | 0.2050 | 0.0355 | — | SWA 0.1916，无提升 |
| **Focal + 类权重 + 特征噪声** | **0.2149** | 0.0504 | **0.1626** | 当前留出最好（噪声量级） |
| 平衡 attention | 0.2082 | 0.0407 | — | — |

给定人工框诊断（LOSO 校准）：baseline 头宏 F1 0.329–0.340；focal 头 0.329；旧模型 0.4546。→ 分级能力本身仍是主瓶颈。

### 6.3 TTA 候选缓存 + validity 加权训练

| 配置 | 验证宏 F1 | 损伤档 F1 | 留出宏 F1 | validity 阈值 |
|---|---:|---:|---:|---:|
| TTA pooled + validity 1.2 | 0.2166 | 0.0584 | 0.1572 | 0.65 |
| TTA attention + validity 1.2 | 0.2117 | 0.0465 | — | 0.30 |
| TTA pooled + 旧模型融合 [0.8,0.4] | 0.2253 | 0.0663 | — | — |

结论：TTA + validity 让损伤档 F1 与重损 TP 略有提高（重损 5→7 个匹配、TP 2），但总体宏 F1 仍停留在 0.21–0.23，留出无显著提升。**第 1 阶段的低成本改动已到瓶颈**。

### 6.4 下一阶段判断

要把墨西哥端到端宏 F1 实质提高，按预期收益排序：
1. **复刻 xView2 冠军两阶段**：UNet 震前分割定位（定位 F1 0.55→0.75+，配合 TTA/4×TTA）+ Siamese 分级；这是唯一能同时解决“定位召回 0.58”和“误报”的结构性改动。
2. **用旧流水线的分级特征**（ViT-L 112 + ViT-B 168 + 纹理，给定框 0.4546）替换/融合当前 RoI 头，先保证分级上限。
3. 更高 token 分辨率（336px/12×12）或 LoRA 解冻（推测 +0.02–0.06）。
4. 指标上增加 xView2 像素综合分，便于与文献比较；建筑级三档宏 F1 不作为唯一验收。


### 6.5 旧模型分级 + TTA 定位（中间方案，负结果）

| 配置 | 验证三档宏 F1 | 损伤档 F1 | 框 F1 | 定位召回 | 说明 |
|---|---:|---:|---:|---:|---|
| 旧模型（原生 swin_mix 定位） | **0.2296** | 0.0708 | 0.5524 | 0.580 | 基线 |
| TTA@0.36 定位 + 旧模型分级 | 0.1894 | 0.0146 | 0.5469 | 0.635 | 误报增加、分类阈值失配 |
| 同上 + proposal 头 validity≥0.65 过滤 | 0.1881 | 0.0146 | 0.5429 | 0.611 | 过滤不足，宏 F1 更差 |

原因：旧分类器的阈值是在旧 localizer 的框分布上校准的，换成 TTA 合并框后分布偏移（框更密、更多低质量框），旧分类器把大量未受损/背景判成损伤或反之；只替换定位端不同时重校准分级端，反而破坏原组合。**结论：混合方案不可行，必须同时重做定位与分级（或整体重校准）**。


## 7. 第 2 阶段：xView2 两阶段复刻（定位 UNet + 检测器微调）实测（2026-11-27 晚）

### 7.1 建筑定位 UNet

- 数据：F 盘 39,346 对 512×512 建筑提取样本（影像 + 0/255 二值掩膜）。
- 模型：ResNet18-UNet（ImageNet 预训练编码器，256 crop，BCE+Dice，2500 步，约 6 分钟）。
- 结果：建筑提取验证 Dice **0.775** / IoU 0.654（best step 2250）。
- xBD 震前建筑多边形微调：243 个场景（墨西哥 130 + 帕卢 113），384 crop、300 步；内部验证 Dice **0.821**。
- xBD 墨西哥验证集掩膜质量：Dice **0.786** / IoU **0.661**。

### 7.2 掩膜用于定位（负结果）

| 用法 | 框 F1 | 完美分级宏 F1 上限 |
|---|---:|---:|
| 掩膜连通域→框 | 0.185 | 0.265 |
| 分水岭实例→框 | 0.073 | 0.283 |
| TTA 框按掩膜收紧 | 0.530 / 0.534 | 0.795 |
| TTA 原始（对照） | **0.547** | **0.825** |
| TTA + 掩膜覆盖率过滤 0.1 / 0.2 | 0.548 / 0.546 | 0.825 / 0.824 |

原因：密集城区建筑在掩膜中粘连，连通域/分水岭无法分离成单栋建筑；xView2 的定位指标是像素级 F1，与我们的“框 IoU≥0.5 一对一匹配”口径不同，不能直接迁移。

### 7.3 检测器微调

- 初始化 `run/swin_loc_mix/detector.pt`（原验证框 F1 0.5524）。
- 墨西哥+帕卢 243 对训练 + 35% 建筑提取辅助样本，lr 8e-5，8 轮 × 80 步。
- 结果：验证框 F1 **0.5546**（+0.002，噪声级）；epoch 1/3/6 分别为 0.5389/0.5369/0.5487。

→ 单时相检测器在同一数据 + 辅助样本上继续微调已无收益。

### 7.4 旧模型分级 + TTA 定位 + 阈值重校准（负结果）

- 用 TTA 框上的旧分类器分数在验证集上重新校准两级阈值：验证宏 F1 0.2022、损伤档 0.0340。
- 34 对留出：宏 F1 **0.1555**（旧模型 0.1557）。

→ 旧分类器的 patch 表征依赖旧 localizer 的框上下文；换框分布后即使重新校准阈值也救不回来。

### 7.5 结论与下一步

单时相定位路线（掩膜 / 检测器微调）与“旧分级 + 新定位”混合路线均无实质收益。剩余两个方向：
1. **双时相 Siamese 检测器**（pre / post / |diff| 输入 + 震后位移增广；需要改检测器输入与训练）；
2. **分级端数据增强**（损伤建筑 CutMix 合成 + 序数损失 + 类权重），把给定人工框宏 F1 从 0.33–0.45 抬到 0.5+。

若两者都无提升，建议按文献口径（xView2 像素综合分 + 给定框分级）报告，并将建筑级三档宏 F1 的 **0.16** 作为该标签集上的现实参考。


## 8. 分级端 CutMix 损伤合成增强（负结果，2026-11-27 晚）

### 8.1 数据构造

- 从 243 个训练场景中选 130 个无损建筑较多的场景作为目标场景；从 3,033 个训练集损伤建筑中选 2,000 个捐赠者（轻损 1,000 循环过采样 + 重损/毁坏 1,000）。
- 按捐赠建筑多边形只粘贴建筑像素（保持目标场景背景），同时修改 pre/post 两张图与 post 标签（矩形多边形 + 捐赠 subtype）。每个目标场景最多贴 8 栋。
- 生成 130 个合成场景；训练集 243 → 373。合成场景损伤计数（含目标场景原有损伤）：轻损 595、重损 457、毁坏 2,574。

### 8.2 结果（墨西哥 27 对验证 / 34 对留出）

| 配置 | 验证宏 F1 | 损伤档 F1 | 34 对留出宏 F1 | 给定框 LOSO 宏 F1 |
|---|---:|---:|---:|---:|
| CutMix pooled（focal+类权重） | 0.2037 | 0.0366 | — | — |
| CutMix attention（重损采样+SWA） | 0.2155 | 0.0500 | 0.1561 | 0.3309 |
| 对照：p1_focal | 0.2149 | 0.0504 | 0.1626 | 0.3293 |
| 对照：p1_tta | 0.2166 | 0.0584 | 0.1572 | — |

给定人工框诊断：自动 0.3575 / tuned 0.3882 / LOSO 0.3309（对照 automatic 0.3548 / LOSO 0.3293）——只有噪声级差异。

### 8.3 结论

合成损伤纹理与真实震害的差异较大，单纯增加损伤样本数量不能解决轻损/重损判别；分级瓶颈在**特征表达与标签质量**，不在样本数量。下一阶段若继续，只剩双时相 Siamese 检测器（定位端）或更换更强的分级特征/基础模型两条路；否则建议按现有最佳配置收敛并如实报告上限。
